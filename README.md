# Siftly

> macOS 向けの写真仕分けアプリ。「未整理」アルバムの写真を、サクサク各アルバムへ振り分ける。

Apple Photos アプリ単体だと、複数の写真を別アルバムへ移動するのが地味に手間です。Siftly は「**1枚ずつ大きく表示 → 行き先アルバムを選んで移動**」を、片手でリズミカルにこなせるよう設計したアプリです。

## 主な機能

- **「未整理」アルバム**を起点に、1枚ずつ／複数まとめて各アルバムへ仕分け
- **未整理以外のアルバム**もソースに選んで仕分け可（移動 or コピーを選択可）
- 写真は Photos の元アルバムに**追加＋未整理から削除**（=「移動」）
- **新規アルバム**をその場で作って移動
- **取り消し** (`⌘Z`) / **やり直し** (`⌘⇧Z`) — バッチ移動も一発で巻き戻し
- **削除予定アルバム**経由のゴミ箱送り — 取り消し可能、まとめて削除可
- **未分類写真の自動取り込み** — どのアルバムにも入っていない写真を「未整理」へ自動追加
- **動画再生**（プレビューで AVPlayer 経由）
- **ピンチで拡大 + 二本指でパン**（NSScrollView ベース、自由 2D 移動）
- **撮影日時 + 撮影場所**を表示（CoreLocation の逆ジオコーディング）
- **お気に入り (`.`)** — Photos の ❤️ フラグを切り替え
- **ドラッグで一気に複数選択** — 範囲塗り＋自動スクロール
- **キーボード操作** — `←/→` 写真切替、`⌘R` 更新、`⌘Z` 取消、`⌘⇧Z` やり直し、`.` お気に入り

## 動作環境

- **macOS 13 (Ventura)** 以降（開発は macOS 26 / Apple Silicon で実施）
- Apple Photos アプリで **「未整理」という名前のアルバム（手動作成）** が存在すること
  - スマートアルバムだと写真を削除できないため、手動アルバムが必須

## ビルド方法

このリポジトリは Xcode プロジェクトを持たず、`swiftc` で直接コンパイルする軽量構成です。Xcode のフルインストールは不要で、**Command Line Tools** だけで動きます。

```sh
git clone https://github.com/YOUR_USERNAME/siftly.git
cd siftly
./build.sh                          # build/Siftly.app を生成
open "build/Siftly.app"             # 起動
```

`/Applications` に正式にインストールしたい場合：

```sh
./install.sh
```

> ⚠️ アドホック署名のみのため、macOS の Gatekeeper で「壊れているため開けません」と表示される場合があります。**システム設定 → プライバシーとセキュリティ** で「とにかく開く」を押してください。

## 使い方

1. Photos.app で **「未整理」** という名前のアルバムを作る
2. 整理したい写真を「未整理」に入れる
3. Siftly を起動、写真ライブラリへのアクセスを許可
4. プレビューを見ながら、右の一覧から行き先アルバムをクリック
5. 不要な写真は **「削除予定」へ** ボタン → あとでまとめてゴミ箱へ

### 一括移動
- 下の写真一覧で**1回クリック**するとプレビュー、**2回目クリック**で選択トグル
- ドラッグで範囲一括選択
- 選択中にアルバムをクリックすると、選択全部がそのアルバムへ移動
